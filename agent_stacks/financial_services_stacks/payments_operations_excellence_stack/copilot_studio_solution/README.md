# Payments Operations Excellence — One-Click Copilot Studio Solution

The **Tier 3** deploy bundle for this agent stack (the "parallel solution bundle"
the stack README refers to). Import these two Power Platform solutions to stand
this industry solution up as **new-generation connected agents** in your own
Copilot Studio environment — no code, no hosting. The agent ingests and screens payments across CHAPS/FPS/SEPA/SWIFT, handles exceptions, and reconciles positions.

**Publisher:** Microsoft AI Business Applications Specialist Team (AIBAST) · customization prefix `aibast`

## What's in the box

| File | What it is |
|------|-----------|

## Import (about 5 minutes)

1. **Copilot Studio → Solutions → Import solution** → upload **`PaymentsOperationsMcpConnectors_1_0_0_1.zip`** → Import.
2. Repeat for **`PaymentsOperationsMcpAgents_1_0_0_1.zip`**.
3. Open the parent agent (**Payments Operations Excellence Assistant**) and **Publish** it.
4. **The one manual step** (no API): on each agent, **Tools → Add a tool → Model Context Protocol →** pick the `… MCP` connector → create the **no-auth** connection → **Add** → **Publish**. See `MANUAL_STEPS.html` for the illustrated version.
5. Test in the agent's **Test** pane. Drag `EVALUATION.csv` into the **Evaluate** tab to load the grounded demo conversations as live evals.

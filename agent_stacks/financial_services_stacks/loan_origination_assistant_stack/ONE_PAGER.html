AGENTIC PROCESS FLOW — 8 STEPS
1Application Submission
Customer submits a loan application via digital channel or branch; Copilot Studio guides the process, ensuring all required data is captured correctly.
Copilot StudioPower Apps
2Open Banking Data
With customer consent, Azure AI analyses Open Banking transaction data to generate an enriched income and expenditure view for affordability.
Azure AIOpen Banking Platform
3Credit Decisioning
The decision engine runs an automated scorecard over bureau, application, and behavioural data; Azure AI flags anomaly cases.
Azure AICredit Bureau API
4Fraud Risk Scoring
The fraud engine runs concurrently with the credit decision, assessing identity, device, and application-level fraud indicators.
Azure AIFraud Prevention
5Offer Presentation
Approved applicants receive a personalised offer via Copilot Studio, dynamically optimised for conversion while staying within risk appetite.
Copilot Studio
6Drawdown Processing
Accepted offers trigger automated drawdown in the core banking system; funds are credited within the required regulatory timeframe.
Power AutomateCore Banking System
7Referred Case Management
Referred applications are presented to underwriters in Power Apps with a full AI-generated assessment; decision and rationale are captured for model feedback.
Power AppsCopilot Studio
